मानस न्यूज-24 PWA — ऑफलाइन सेव खबरों वाला संस्करण

GitHub Pages repository के मुख्य स्तर पर ZIP की सामग्री अपलोड/अपडेट करें।
मुख्य URL:
https://manasnews24.github.io/manas-news24-pwa/

क्या नया है:
1. ऐप का होम पेज और आवश्यक फाइलें सर्विस वर्कर में कैश होती हैं।
2. ऑनलाइन रहते हुए Blogger फीड की नवीनतम 25 खबरें ऐप में सेव होती हैं।
3. इंटरनेट बंद होने पर पहले से सेव खबरों का पाठ ऐप में पढ़ा जा सकता है।
4. नई खबरें पाने के लिए "खबरें अपडेट करें" दबाएँ।

सीमाएँ:
- यह संस्करण Blogger की Atom JSONP फीड पर निर्भर है। यदि Blogger फीड बंद/सीमित है, खबरें अपडेट नहीं होंगी।
- लेख के बाहरी चित्र इंटरनेट के बिना उपलब्ध होने की गारंटी नहीं है।
- खबरें केवल उसी मोबाइल/ब्राउज़र में सेव होंगी जिसमें ऐप इस्तेमाल किया गया है।
- यह ZIP GitHub पर अपने-आप प्रकाशित नहीं होती; repository में मौजूदा फाइलें अपडेट करनी होंगी।


नया अपडेट: ऐप शेयर करें बटन जोड़ा गया है। इससे ऐप का लिंक WhatsApp आदि पर साझा किया जा सकता है।
