मानस न्यूज-24 PWA — सुरक्षा एवं स्थिरता अपडेट (V6)

यह पैकेज मौजूदा मानस न्यूज-24 PWA का सुधारित संस्करण है। मौजूदा मुख्य सुविधाएं बरकरार रखी गई हैं: Blogger से ताजा खबरें, इस डिवाइस में ऑफलाइन खबरें सेव करना, ऐप इंस्टॉल संकेत, खबरें अपडेट करना और ऐप शेयर करना।

मुख्य ऐप पता:
https://manasnews24.github.io/manas-news24-pwa/

इस संस्करण में किए गए सुधार:
1. खबरों के HTML में खतरनाक टैग और URL योजनाओं की सफाई मजबूत की गई है; सुरक्षित सापेक्ष लिंक भी काम करते रहेंगे।
2. इस डिवाइस में अधिकतम 25 खबरों का पाठ सेव रखा जाता है।
3. सर्विस वर्कर केवल manas-news24-shell- नाम से शुरू होने वाले अपने पुराने कैश हटाता है; अन्य परियोजनाओं के कैश नहीं हटाता।
4. ऑफलाइन स्थिति में पहले से सेव खबरें पढ़ी जा सकती हैं।
5. ऐप शेयर बटन मौजूदा ऐप URL साझा करता है।
6. सर्विस वर्कर कैश अपडेट को fetch event के जीवनकाल से जोड़ा गया है।

महत्वपूर्ण सीमाएं:
- खबरें Blogger की Atom JSONP फीड से आती हैं। फीड उपलब्ध न होने पर नई खबरें अपडेट नहीं होंगी।
- खबरें केवल उसी मोबाइल/ब्राउज़र में सेव होती हैं; दूसरे मोबाइल में अपने-आप नहीं पहुंचतीं।
- लेखों के बाहरी चित्र ऑफलाइन उपलब्ध होने की गारंटी नहीं है।
- यह फ्रंट-एंड PWA है। इसमें पत्रकार लॉगिन, संपादकीय डैशबोर्ड, केंद्रीय डेटाबेस या मालिक का एडमिन डैशबोर्ड शामिल नहीं है। इन सुविधाओं के लिए अलग सुरक्षित बैकएंड बनाना होगा।

अपलोड करने से पहले सावधानी:
- ZIP फाइल को सीधे GitHub पर अपलोड न करें। ZIP को Extract करके उसके अंदर के आठों आइटम repository के मुख्य स्तर (root) पर अपलोड/अपडेट करने होंगे।
- मौजूदा लाइव ऐप पर बदलाव करने से पहले repository की वर्तमान फाइलों का बैकअप रखें।
- यह पैकेज अपने-आप प्रकाशित नहीं होता। GitHub Pages पर प्रकाशित करने के लिए repository में फाइलें commit करनी होंगी।
- अभी यह पैकेज केवल जांचा हुआ विकास पैकेज है; लाइव वेबसाइट पर प्रकाशित नहीं किया गया है।
