प्रकाशन सुरक्षा: केवल संपादकीय रूप से स्वीकृत खबरें यहाँ आएँगी। पहले Blogger में ड्राफ्ट बनाया जाएगा, फिर उसी पोस्ट को स्पष्ट पुष्टि के बाद लाइव किया जाएगा। वास्तविक Blogger URL मिलने पर न्यूज़रूम में खबर की स्थिति प्रकाशित होगी।

एडमिन अनुमति आवश्यक

Blogger पर वास्तविक प्रकाशन केवल एडमिन खाते से किया जा सकता है।

मुख्य न्यूज़रूम पर लौटें

Blogger कनेक्शन सेटिंग

Google Cloud Console में Blogger API v3 सक्षम करें और Web OAuth Client ID बनाएँ। नीचे Client ID दर्ज करें। यह सार्वजनिक पहचान है, पासवर्ड या Client Secret नहीं।

Google OAuth अभी कनेक्ट नहीं है।

अनुमति केवल Blogger प्रबंधन के लिए माँगी जाएगी। Access token अस्थायी रूप से मेमोरी में रहेगा; ब्राउज़र स्टोरेज में नहीं। अधिकृत JavaScript origin वही होना चाहिए जहाँ यह न्यूज़रूम पेज चलेगा।
